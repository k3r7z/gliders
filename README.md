# CPAE WebSystem
This is the web system for the "Club de Planeadores de Esperanza" (CPAE).
The goal behind this is to automate "paper" processes as well as having a relevant data from the club members and aircrafts (gliders and airplanes). Every member would have an account in the system and, depending on his/her role, would be able to access important club info, see flight logs, alter personal data, among others.
